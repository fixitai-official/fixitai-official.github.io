    How to use FIXIT AI

    The current download is a developer prototype. You need Node.js to run it.

    1

    Download & extract

    Download the ZIP file and choose Extract All in Windows File Explorer.

    2

    Install & start

    Install Node.js LTS, open a terminal inside the extracted fixit_ai folder, then run npm install and npm start.

    3

    Explore safely

    Use local diagnostics, choose a guide for your issue, and save a report if needed.

    ⚠️ This is source code, not a one-click Windows installer. First setup requires internet to download dependencies. Review software before running it. Get Node.js ↗

    Frequently asked questions

    Does FIXIT AI use artificial intelligence today?

    Not yet. The current prototype provides local checks and built-in guidance. A real AI integration is a future goal.

    Can FIXIT AI automatically repair my PC?

    No. It provides information and suggested steps; it does not perform automatic repairs.

    Is the download a Windows installer?

    No. It is a source ZIP for an Electron desktop prototype. You need Node.js and npm to launch it.

    Can I buy FIXIT AI+ now?

    No. FIXIT AI+ is a concept for a future premium tier. No checkout or payment collection is available.

    Does the prototype work offline?

    Local diagnostics and built-in guides can work without a live internet connection after dependencies have been installed. Initial setup requires internet.
