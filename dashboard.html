Fix guides

Start with low-risk checks. Stop if a step doesn't match what you see.

◷PERFORMANCE

When your PC feels slow

  1. Save your work and restart if you have not restarted recently.
  2. Open Task Manager with Ctrl + Shift + Esc.
  3. On the Processes tab, check which apps use the most CPU or memory.
  4. Close only apps you recognize and are not using.
  5. Check available storage in Windows Settings.
▤STORAGE

When storage is nearly full

  1. Open Settings → System → Storage.
  2. Review temporary files before removing anything.
  3. Use Windows Storage Sense if appropriate.
  4. Back up important files before moving or deleting them.
  5. Never delete unfamiliar system folders to free space.
⌁CONNECTIVITY

When Wi-Fi or internet fails

  1. Check whether other devices can access the internet.
  2. Confirm Wi-Fi is enabled and airplane mode is off.
  3. Reconnect to your known network.
  4. Restart the router only if you can safely do so and others are aware.
  5. If it still fails, note any exact error message before changing settings.
i These are general first steps, not a guarantee of a diagnosis. Never share passwords or verification codes with support tools.
