Questions, answered.

Is FIXIT AI free?

The source ZIP is available free on this page. Node.js and npm are also free to use. Internet access is needed to download the Electron dependency during setup.

Does it work on phones or Mac?

This prototype is designed for Windows desktop use. It has not been packaged or tested for macOS, Linux or mobile devices.

Does it use AI already?

Not yet. The current version uses local read-only checks and built-in troubleshooting guides. It does not connect to an AI model.

Will it fix my PC automatically?

No. This prototype does not automatically change settings or delete files. It offers guidance so you can decide what to do.

Is this a finished, verified release?

No. It is an early prototype and has not yet been runtime-tested on a range of Windows devices. Please use it carefully and report problems.
